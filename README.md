## Installation

Install via NPM:

```bash
npm install @saiuttej/nestjs-encryptions
```

Install via Yarn:

```bash
yarn add @saiuttej/nestjs-encryptions
```

Install via PNPM:

```bash
pnpm add @saiuttej/nestjs-encryptions
```
